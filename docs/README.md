## 文档维护约定

1. 文档必须区分“已经实现”和“计划实现”，不要把路线图能力写成现状。
2. 端口、数据路径、表结构、去重键或安全行为变化时，同步更新 README 与架构文档。
3. 新增关键依赖时，在技术栈文档记录用途、版本策略和为什么选择它。
4. 完成路线图条目后，补充验证方式，再将状态从规划改为已完成。
5. 不在文档、截图、示例数据中提交真实证书私钥、Token、Cookie 或业务敏感响应。
